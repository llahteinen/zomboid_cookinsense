## Cookin Sense mod for Project Zomboid B42

This mod extends some vanilla cooking recipes to be more flexible and...to have some common sense.

You can for example add some JAM ON YOUR CEREAL NOW!!!!!!!11 And you can craft the portion directly without needing to pour the milk in the bowl first and the cereal on it like a psychopath.

You can also make pizza marinara. Pizza without cheese. Yes, that is 100% a real thing. Pizza can be made without cheese. And if you want, you can add the cheese later as a topping. Moldy or non.

### Installation
1. Dowload latest ZIP from the [Releases](https://github.com/llahteinen/zomboid_cookinsense/releases) section
2. Unzip to %userprofile%\Zomboid\Workshop\
    - e.g. C:\Users\John\Zomboid\Workshop\
3. Go cook some sensible treats for you!
